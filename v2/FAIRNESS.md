# 公平性、威胁模型与评分边界

## 三种不同的证明

**可重放**证明给定种子和动作得到同一轨迹；它不证明玩家没有事先看过答案。**裁判签名**证明某个裁判密钥对这份完整记录和参与者声明签了名；它不证明输入声明里的模型真的执行了动作。**严格模型基准**还要求统一条件、监督参与者身份和工具、保密留出种子及多局统计。这三者不能互相冒充。

GitHub Pages 上运行的是明确标记的浏览器练习版。用户可以检查脚本、浏览器存档和自己的进程，因此该模式没有强秘密边界。练习记录仅保存在当前浏览器；不是跨用户共享的官方榜。

服务端模式由 `v2/server.mjs` 持有世界。它只提供显式列出的 UI 静态文件与公开观察接口，不提供引擎模块、运行目录、密钥、种子或进行中的完整报告。服务端榜仅接受裁判自己完成和签名的运行，不接受客户端上报一个分数；名字仍标为 self-declared。不同引擎版本、内容版本和难度分开筛选。

**同一操作系统用户拥有读取服务器文件的权限时，HTTP 隔离无法阻止其直接读盘。** 严格评测必须让裁判和被测代理处在独立容器/主机/权限域，代理只获得规定的公开 API；不能同时把裁判目录、shell、数据库或另一局赛后答案交给模型。

## 公平世界不等于没有随机性

人物的意图、关系归属、初始日程与公共危机由种子提前确定。世界承诺与种子承诺从第一步提供，结束后公布可重放材料。随机取样由事件键驱动，不随查询次数变化。重复观察、免费档案检索、非法动作或重复网络请求不应该重掷某个证据。

同名人物、文书差错、正常工具、可信与不可信证人都可能出现在合法和危险个体中。职业、地区、行李和措辞不是独立的判罪标签。表述池在确定可观察证据信号后独立抽样，措辞模板不携带隐藏类别 ID。公布检验错误率是公开规则的一部分；学会正确使用概率与证据不是作弊。

对手只能从滞后的公开执法统计中学习，有最小样本要求和有限改装预算。它不能读取概率、摘要或假设，不能在被拒后将无辜者改成危险者，也不能在被放行后才决定身份。它可以有成本地改善外观，包括文书外观，不能同时抹掉所有独立调查来源。

这不构成“任何随机局面都必定可解”的数学证明。开发中的 oracle 对照只检验在知道身份时资源机制有可行路线；观察受限玩家还面临不可消除的误差。更多种子、人工审查和最优策略研究仍有价值。

## 防投机与审计

- 验证动作必须发生在状态变更之前：拒绝无效 revision、越界概率、未知字段、杜撰证据、重复调查和预算不足。
- 付费调查有成本与来源相关性；同一人的重复调查不是独立抽样。
- 隔离有容量、时间和城库成本；正常往来的拒绝会影响供给与民意。
- 第 42 天不清空损失队列，任期末继续兑现已登记责任。
- 裁判拒绝客户端指定种子、真值和分数；持久请求 ID 防止重试执行两遍。
- 完整报告与真值在一局结束后才解锁。公共后果属于环境反馈，不与隐藏真值表混淆。
- 日志重放重新计算世界、观察与转移，并比较完整报告，不能只校验一条哈希链而相信伪造的总分。

## 指标不要夸大

报告的“无辜强制率”包含拒绝和隔离，不等于现实法律意义上的误判率。“适应后漏放”是描述性统计，没有反事实对照时不能称为适应的因果增量。“证据引用覆盖率”只统计引用，不能证明模型真的理解或有效利用了证据。缺失概率时 Brier 为 null，不凭空赋予满分。

每个动作保留当时可见证据和可公开摘要，让人区分坏运气、证据不足、资源取舍、忽视信息和事后编造理由。没有要求或保存私密思维链，也没有用文风给模型推理能力打分。

## 部署须知

默认只监听 `127.0.0.1:8788`。对外运行前需要 HTTPS 反向代理、操作者身份认证、资源限制、备份、磁盘权限、访问记录保护与持续安全维护。只有确认代理设置后才配置 `HOST` / `BLACKGATE_ALLOWED_HOSTS`。不要公开 `.blackgate-v2`，不要将它加入 Git、Pages、容器镜像或下载包。

裁判签名私钥保存在私有运行目录；只有对应公钥可以分发。丢失密钥会改变裁判身份，不应把新密钥冒充旧签名的证明。活动会话保存服务端生成的种子、动作与 token 的哈希，不把明文令牌写进持久日志；浏览器会话令牌位于 sessionStorage，勿复制给他人。

当前实现是经过功能与边界回归测试的发布版基础设施，不是经过外部渗透测试的托管服务。发布到 GitHub 不等于已经向互联网部署了权威裁判集群。
