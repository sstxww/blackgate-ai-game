# Blackgate II · 深渊议事厅

**42 天、不完全信息、动态关系网络与延迟责任的长程决策游戏。**

[在线新版](https://sstxww.github.io/blackgate-ai-game/v2/) · [开发校准实测](./reports/BALANCE.md) · [完整数据清单](./data/manifest.json) · [公平性与安全边界](./FAIRNESS.md)

v2 没有把经典版的 NPC 数量简单翻倍，也不把“证件不一致”当作犯罪判定。你管理的不是一个分类器，而是一座依赖通行、贸易、粮食、医疗和信任维持运转的城市。城外势力能观察你的公开审查行为，但不能读取你的概率预测、公开理由或未来动作，也不能在你作出决定后改写一个人的真实意图。

## 已实现的规模

| 项目 | v2.0.0 实际配置 |
|---|---|
| 任期 | 42 天，最后结算已承诺的延迟后果 |
| 每天入境档案 | 10→15，每七天增加一人；完整任期 525 次入境决策 |
| 每局人物库 | 1,024 人；不是所有人都会在这一局到达 |
| 关系世界 | 128 个网络、2,304 条定向关系，其中有跨网络的普通往来 |
| 活跃长程事件 | 每局 12 个网络被抽中激活，来自 16 种事件机制 |
| 表面资料 | 16 地区、12 职业、48 种证据表述、12 种自述背景 |
| 调查 | 6 种渠道，存在费用、误报、漏报和证据相关性 |
| 政策 | 8 种；当日、三日后效果与切换成本公开 |
| 公共危机 | 6 个带种子扰动的危机，提前四天预警 |
| 难度 | 高难度 / 深渊 / 梦魇；不同难度分榜 |
| 开发数据包 | 8 个公开开发世界：8,192 个人物实例、1,024 个网络、18,432 条关系；6,820,515 字节 JSONL |

**生成实例不等于人工编写的独立题目。** 仓库提供大规模可校验实例、关系、事件和生成器，但没有声称拥有几千个手工打磨的独立剧情。公开开发数据包含开发用真值，不能作为保密评测集。正式裁判每局用新的 256 位随机种子，不从公开实例里抽取现成答案。

## 开始游戏

### 在线玩或让普通聊天 AI 玩

打开 [v2 在线入口](https://sstxww.github.io/blackgate-ai-game/v2/)，填写参与者名称、类型和难度，然后新开一局。人类可直接调查、放行、拒绝、隔离和制定政策。

聊天 AI 不需要 Codex、电脑控制或 API Key。点击「复制玩家可见状态 + 规则」，把内容发给聊天 AI，再把它的 JSON 粘回网页。「关联档案检索」允许免费查阅已经公开的旧资料，不会揭示隐藏记录。

AI 回复示例：

```json
{
  "revision": 0,
  "action": "investigate",
  "test": "registry",
  "reason": "当前文书差异存在无辜解释，先用独立户籍来源核验。"
}
```

`revision` 必须取自当前状态，不能照抄这个示例的 0。调查后再根据新状态决策。

```json
{
  "revision": 1,
  "action": "reject",
  "p_threat": 0.72,
  "evidence_ids": ["本局真实返回的证据ID"],
  "reason": "两个不同来源出现无法同时成立的记录；考虑当前治安与误拒成本后拒绝。"
}
```

`p_threat` 是 **P(该人具有危险意图)**，不是“对动作的自信程度”。理由和概率均可省略。只记录自愿公开的简短决策依据，不要求私密思维链。

### 独立裁判

```bash
npm ci
npm start
```

打开 `http://127.0.0.1:8788/v2/`。Node.js 24 是本版本自动测试使用的运行环境。裁判不需要浏览器，也不会连接或消耗任何模型 API。

经典版仍可通过 `npm run start:classic` 启动在 8787 端口；经典玩法文件保留。旧 API 的示例使用经典版端口，不自动兼容 v2 动作协议。

**网页顶部会明确显示当前模式。** GitHub Pages 是浏览器练习版，不能在客户端保密随机种子与代码；独立裁判把真值、随机种子和签名密钥留在服务端。不要把浏览器练习成绩包装成正式验证成绩。

## 如何才能活下来

城市有治安、经济、民意、粮食、健康、城库、渗透七个指标。前五项归零、渗透达到 100，或城库低于 -25，任期就会结束。为了避免“最后一天全放行然后逃避后果”，第 42 天之后仍会结清所有已登记的延迟义务；此期间不再给新行动额度。

全放行会失去边境控制；全拒绝会损害合法供给和民意；隔离占用三处床位，每次两天，还要支付设施成本。把目标安全地拒之门外，不会立刻得到一个能够反推身份的“正确答案奖励”。自然发生的城市来信会披露后来观察到的实际后果，但完整隐藏身份表只在任期结束后开放。

### 调查预算

每天 8 点，第 13 天起 10 点；情报协作政策额外增加 3 点。户籍核验与访问证人各 2 点，货物深检与生物鉴定各 3 点，关系档案 2 点，两日跟踪 4 点。同一案件同一渠道只能使用一次；同一个人再次出现，不会重新掷出另一份独立调查结果。

所有渠道都可能出错。生物鉴定只对生物危害敏感，不能排除腐败、暴力或走私。证人与跟踪记录共享部分线人来源，不能当作两份完全独立的证据相乘。公开规则提供渠道的敏感度和误报率，要求模型学会使用这些信息，而不是靠猜游戏作者的词汇习惯。

### 关系网与长期假设

人物可以付款、委托、同行、交接或曾共事。普通往来跨越网络，因此“认识可疑人”不等于危险。事件包含药材冷链、北门夜班、失踪矿工、粮仓借据、难民互助等机制；每种机制都具有合法版本与危险版本，名称本身不是答案。

付费档案和跟踪返回关系、流水批次与人物 ID。公开旧证据和城市来信全部可检索。发现关联后，可以提交 `investigate_network`：3～8 个已见人物、至少 3 条相关证据且来自至少 2 名人物，花费 5 点，三天后得到独立调查结果。成功的网络调查可以中断危害并减轻其尚未兑现的损失；无依据地调查合法网络也有成本。

每次行动还可附上待检验假设：

```json
{
  "hypothesis": {
    "members": ["P-人物一", "P-人物二", "P-人物三"],
    "p_hostile": 0.6
  }
}
```

这是完整动作的附加字段，不是独立动作。ID 必须来自当前已知档案。赛后报告记录假设提出时间、关系匹配及当时是否早于事件兑现，而不事后替模型编造“早已识破”的说法。

### 有限制的敌方适应

第 13 天开始，每三天观察一次最近的公开审查历史，至少滞后两天、每类至少八个样本后才能调整伪装。可调整职业、地区、行李和文书外观，不会改写真实意图。深渊模式每轮每个网络最多三次改装，总改装不超过六次；其他难度有不同额度。

敌人不能直接读取 `reason`、`p_threat`、隐藏记忆、模型名称或下一步动作。它只尝试利用可观察的审查差异。适应记录与被放行的伪装对象在赛后单独统计，**这不是因果反事实意义上的“适应让模型多错了几次”**。

### 政策和危机

夜间可以维持常规、保障贸易、救济、公共卫生、情报协作、轮岗审计、配给或有限宵禁。每种政策的当日和三日后资源变化都公开。改变政策要支付组织成本；不是“每天都换一个政策才正确”。储备达到缓冲线和匹配的专项政策可以减轻危机，但没有一条政策能免疫全部风险。

## 赛后报告

每个完成或失败的任期都生成 JSON；网页也提供 Markdown 报告。包括日级资源轨迹、动作分布、公开理由、证据引用、概率预测、误放与无辜强制措施的分子/分母、Brier 分数与预测覆盖率、提前阻断网络数、对手适应记录、逐项延迟资源归因、期末清算、完整动作链和赛后真值。

综合分为 100 分：公共资源 35、安全拦截 25、无辜保护 20、生存 20。天数另列，通关必须通过期末清算。概率校准、证据引用和关系推理指标独立展示，避免用一个不透明总分假装刻画所有能力。

**坏结果不自动等于坏决策，好结果也不自动证明推理正确。** 报告保留当时公开证据和实际后果，供人复盘；没有给每个局面强塞一个“唯一理想动作”。

## API 与重放

`POST /api/v2/sessions` 接受 `model`、`participant_type`、`difficulty`。服务端选择种子并返回 `session_id`、一次性展示的会话 `token` 和公开观察。

后续访问需 `Authorization: Bearer <token>`：

| 方法 / 路径 | 功能 |
|---|---|
| GET `/api/v2/info` | 公开规则与模式 |
| GET `/api/v2/sessions/:id/state` | 当前公开观察 |
| POST `/api/v2/sessions/:id/action` | 执行动作；要求 `revision` 和 `X-Request-Id` |
| GET `/api/v2/sessions/:id/archive?q=...` | 已公开档案检索 |
| GET `/api/v2/sessions/:id/report` | 任期结束后取得完整报告；进行中返回 409 |
| GET `/api/v2/leaderboard?difficulty=abyss` | 此裁判同版本、同内容版本、同难度成绩 |
| GET `/api/v2/public-key` | 此裁判的 Ed25519 公钥 |

同一请求 ID 重试同一内容不会执行两次；同一 ID 换内容、过时 revision 会被拒绝。动作在会话内串行化，服务重启后从持久日志恢复。

```bash
npm run replay -- downloaded-report.json
npm run replay -- downloaded-report.json trusted-referee-public-key.pem
```

重放要求匹配引擎/内容版本，会重新生成世界和每一步公开观察，核对日志及完整报告。改变分数、身份审计或动作摘要会导致校验失败。公钥必须由独立可信渠道提供，不能因为报告自己夹带一个公钥就相信它。

## 验证结果与边界

本版本包含引擎和 API 自动测试、浏览器实际操作测试以及 72 局开发校准。实际输出位于 `v2/reports/`，校准结果提供逐局记录、分母、95% Wilson 区间和源码 SHA-256。

8 个开发种子中，全放行、全拒绝、隔离优先、只看证件、有异常就拒绝这五类固定策略均未通关；带政策反应的异常规则、证据基线、记忆基线各通关 1 局。读取隐藏身份的 oracle 对照通关 8/8，**它只是检查机制可行性的作弊对照，不是玩家成绩**。

这些不是 Astra、Pro、Jev 或人类的实测成绩。开发种子已经公开且参与调试，不能当作严格留出集；8 个种子置信区间仍很宽。此版本不能据此宣称测出了任何模型的能力上限，也不能保证所有新种子对观察受限的玩家都存在高概率通关策略。

严肃比赛还需要独立裁判部署、保密留出种子、统一提示词/工具/预算/记忆条件、监督模型身份与工具边界、多种子统计，以及更丰富的人工剧情与网络拓扑。v2 已实现可运行的基础设施；没有把这些尚未完成的工作标成“正式权威排行榜”。
